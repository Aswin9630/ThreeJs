# Contributing to Temple Run – Three.js 🎮

Thank you for your interest in contributing! Your contributions — big or small — are **welcome** and appreciated. 🚀  

By contributing, you agree to follow the guidelines below to help keep the project organized and friendly.

---


## How to Contribute

1. **Fork** the repository to your GitHub account.  
2. **Clone** your fork locally:
   ```bash
   git clone https://github.com/Aswin9630/ThreeJs.git
   cd ThreeJs
   
3. **Create a new branch** for your feature or bugfix:
   ```bash
   git checkout -b feature/your-feature-name

4. Make your changes in your branch.
5. **Commit your changes** with clear, descriptive messages:
   ```bash
   git commit -m "Add dynamic coin collection feature"

6. **Push** your branch to your fork:
   ```bash
   git push origin feature/your-feature-name
7  **Open a Pull Request** from your branch → main repo.
